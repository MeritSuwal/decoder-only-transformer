# Decoder-Only Transformer Language Model

A decoder-only Transformer language model implemented from scratch in **PyTorch**, following Andrej Karpathy's *Let's build GPT from scratch* tutorial.


### Implemented Components

* Character level encoding and decoding
* Token and positional embeddings
* Self-attention
* Multi-head self-attention
* Feed-forward neural networks
* Residual connections
* Transformer decoder blocks


## Tech Stack

* Python
* PyTorch
* Jupyter Notebook

## Learning Goals

The project was built to gain a practical understanding of **Transformer architecture, self-attention, language-model training, and autoregressive text generation** without relying on a pretrained language model.
